# بررسی نسخهٔ تحویلی

تاریخ بررسی: ۲۳ اکتبر ۲۰۲۶.

| بررسی | نتیجه |
| --- | --- |
| نصب وابستگی از checkout تمیز | موفق، با `npm ci` |
| بررسی TypeScript | موفق |
| ساخت رابط و سرور | موفق، با Node.js 26.12.1 |
| تست‌های اصلی | ۱۴۲ موفق، صفر ناموفق، یک skip اختیاری |
| تست‌های مرورگر | هر ۱۵ تست موفق |
| پخش خودکار دمو | هر هشت فصل، توقف در ۲۶۰ ثانیه |
| توقف، ادامه و بازنشانی | بررسی شد |
| لغو انتشار، شکست ساخت و استعلام پاسخ نامشخص | بررسی شد |
| فونت وزیرمتن و عرض موبایل | بررسی شد |
| اجرای بستهٔ آماده پس از Extract | موفق، بدون node_modules |
| الگوهای توکن و شناسه‌های خصوصی در فایل‌های Git | موردی یافت نشد |

تست‌های اصلی از یک پوشهٔ تمیز، بدون فایل‌های خصوصی `.local/` هم اجرا شدند و همان نتیجه را داشتند. تست اختیاریِ skipشده به نصب جداگانهٔ CLI رسمی و کتابخانهٔ Got آن نیاز دارد؛ سایر تست‌ها اجرا شدند.

تست مرورگر محلی از Chrome نصب‌شده و متغیر `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` استفاده کرد. برای تکرار با Chromium مستقل، از `npx playwright install chromium` و `npm run test:e2e` استفاده کنید.

این بررسی‌ها صحت دموی محلی و رفتارهای آزموده‌شده را نشان می‌دهند؛ داده‌های دموی ضبط شبیه‌سازی‌اند و نتیجهٔ تست‌ها تأیید اتصال یا استقرار در حساب واقعی لیارا نیست.
