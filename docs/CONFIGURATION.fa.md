# پیکربندی و مرزهای نسخهٔ تحویلی

## دو سرور مستقل

- `npm run demo` فقط فایل‌های ساخته‌شده را روی `127.0.0.1:4322` می‌دهد؛ هیچ runtime یا API متصلی راه نمی‌اندازد.
- `npm start` سرور اصلی را روی `127.0.0.1:4310` اجرا می‌کند و شواهد، دیتابیس و فایل‌های تعمیر را در `.local/` می‌سازد.
- پورت‌ها با `LIARA_DEMO_PORT` و `LIARA_PORT` قابل تغییرند.

سرورها برای استفادهٔ محلی طراحی شده‌اند؛ آن‌ها را بدون طراحی احراز هویت و استقرار مناسب، به یک سرویس عمومی چندکاربره تبدیل نکنید.

## ورود و تنظیمات

دموی ضبط هیچ ورودی محرمانه‌ای نمی‌خواهد. در حالت اصلی، مسیر Codex با `LIARA_CODEX_BIN` یا `CODEX_CLI_PATH` تعیین می‌شود؛ در حالت عادی از `codex` روی PATH استفاده می‌شود. ورود Codex باید روی رایانهٔ اجراکننده انجام شده باشد.

سرور فایل `.env` را خودکار نمی‌خواند. متغیرهای نمونهٔ `.env.example` را فقط در پوستهٔ محلی تنظیم کنید. در Windows، `scripts/start-with-liara.ps1` می‌تواند توکن را به‌صورت مخفی و فقط برای عمر همان پردازش دریافت کند. توکن را در Git، رابط مرورگر یا دستور قابل اشتراک قرار ندهید.

## شناسه‌های نمونه

شناسه‌های مالک، تیم، برنامه و شبکه در قراردادهای تست و آداپتورهای محدودشده با شناسه‌های مصنوعی جایگزین شده‌اند. تطبیق سخت‌گیرانهٔ این شناسه‌ها بخشی از رفتار فعلی است. برای اتصال به منابع واقعی، قراردادهای `scope-constants.ts`، `application-creation-contract.ts` و `initial-deployment-contract.ts` باید آگاهانه برای حساب مجاز تنظیم و آزمون شوند؛ صرف افزودن توکن به معنی آماده بودن این مسیرها نیست.

عملیات تغییر ابری به‌صورت پیش‌فرض غیرفعال است. `LIARA_ENABLE_DEPLOYMENT=1` به‌تنهایی مجوز انسانی یا تأیید مقصد ایجاد نمی‌کند. دموی ضبط مستقل از همهٔ این تنظیمات است.

## شواهد تاریخی اختیاری

نسخهٔ اولیهٔ پروژه به یک snapshot خصوصی، ZIP سورس و hashهای ثبت‌شده در `.local/` اشاره می‌کرد. این داده‌ها در مخزن عمومی قرار ندارند و راه‌انداز اصلی بدون آن‌ها هم می‌تواند اجرا شود. مسیر مرتبط در رابط، نبود شواهد را توضیح می‌دهد و اجازهٔ تعمیر آن baseline را نمی‌دهد.

برای نمایش مستقل از این شواهد از `/?demo=recording` استفاده کنید. برای تعمیر واقعیِ محلی، fixture عمومی `fixtures/http500-site` در پروژه وجود دارد و اجرای آن به Codex و Node.js 26+ نیاز دارد.

## تست‌ها

تست‌ها با سرویس‌های ساختگی، دیتابیس حافظه‌ای و workspaceهای موقت اجرا می‌شوند. `npm test` اجازهٔ اقدام ابری واقعی نمی‌دهد. برای آزمون Got در `cli-preflight.test.ts`، نصب جداگانهٔ CLI رسمی در `.local/official-cli` لازم است؛ نبود این ابزار، فقط همان آزمون اختیاری را skip می‌کند.

متن‌های دارای کلید خصوصی، رمز و توکن در برخی تست‌های پاک‌سازی، دادهٔ ساختگی برای بررسی حذف اطلاعات حساس هستند؛ از هیچ توکن واقعی در مخزن استفاده نشده است.
